# Writing & Presentation Rules

- **Never use em dashes (`—`):** Do not use the em dash character (`—`) in chat responses, markdown documents, code comments, UI copy, or presentation slides. Use colons, commas, parentheses, or separate sentences instead.
- **Minimal slide text:** Keep presentation slides clean with a white background, Google brand colors, and minimal text.
